# نطاق النسخة الأولى (MVP) والمراحل

مبني على مراجعة وثيقة الهيكل: الأقسام اللي فيها منطق برمجي تبدأ أولًا، والأقسام اللي فيها
محتوى ديني كبير تتأجل لحد ما تتحل مسألة المصادر والتراخيص والمراجعة.

## داخل النطاق

| القسم | ملاحظة |
|---|---|
| 1 القرآن (حفص + بحث + علامات) | القراءات والترجمات والتفاسير تتأجل |
| 5 الأذكار | من مصدر مفتوح بعد التحقق من رخصته |
| 6 المواقيت والقبلة | تُحسب offline بدون API |
| 7 الزكاة (مال، تجارة، ذهب، فطر) | الأسهم والعملات الرقمية والعقارات تنتظر تحديد مرجع فقهي معلن |
| 8 المواريث | اختبارات للحالات الخاصة: العول، الرد، الأكدرية |
| 10 الحفظ والتصحيح | صح/غلط فقط، وتكرار متباعد بخوارزمية جاهزة |
| 38 الورد والخطط | بلا مخاطرة محتوى |
| 39–41 الواجهة والإعدادات والحساب | الحساب اختياري |

## يتأجل

الفيديو الكرتوني، البث المباشر، الأقسام 2 و13 و30–33، ومحتوى الأقسام 21 و22 و25 و26.
الأطفال (24)، والولاء والبراء والجهاد والحدود والسياسة الشرعية، والشهادات وإعداد المفتي.

## المراحل المقترحة

| المرحلة | المحتوى |
|---|---|
| 0 | هذا المستودع: schema وفحص آلي وبناء قاعدة المحتوى |
| 1 | هيكل Flutter (RTL، داكن، Drift)، المواقيت والقبلة والهجري، القرآن قراءة وبحث |
| 2 | الأذكار من قاعدة المحتوى، الورد والخطط، الإشعارات المحلية |
| 3 | حاسبة الزكاة، ثم المواريث بمجموعة اختبارات للحالات الخاصة |
| 4 | الحفظ والتكرار المتباعد، ثم الأربعين النووية ورياض الصالحين بعد مراجعة |
| 5 | حساب اختياري ومزامنة بيانات المستخدم عبر Supabase، والمشاركة وروابطها |

الترتيب اقتراح قابل للتغيير حسب أولوياتك.

## الـ Stack

| الطبقة | الاختيار |
|---|---|
| التطبيق | Flutter + Drift (SQLite مع FTS5) |
| المواقيت والقبلة والهجري | `adhan` و`flutter_qiblah` و`hijri` |
| الإشعارات | `flutter_local_notifications` |
| الصوت | `just_audio` + `audio_service` |
| الباك | Supabase: Auth ومزامنة بيانات المستخدم فقط |
| المحتوى | هذا المستودع، وCI يبني ملف SQLite |
| التوزيع | Cloudflare (R2 للحزم، Workers لروابط المشاركة، Pages للموقع) |
| النشر | Android أولًا، وAPK على GitHub Releases |

حدود الباقات المجانية وشروط الحزم تتغير؛ راجعها قبل الاعتماد عليها.
