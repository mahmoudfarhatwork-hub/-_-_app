# المصادر وحالة التحقق

كل المصادر هنا **لم يُتحقق منها بعد**. قبل الاعتماد على أي مصدر: افتح صفحة الترخيص أو شروط
الاستخدام، وسجّل الرابط وتاريخ الاطلاع والشروط (إسناد، استخدام تجاري، إعادة توزيع) في العمود الأخير.

## ملاحظات

- Firebase Dynamic Links أُغلقت في أغسطس 2025؛ روابط المشاركة القصيرة ستكون عبر Cloudflare Workers.
- الصوتيات والكتب حقوقها لأصحابها؛ في قسم الدروس تُستخدم روابط فقط.
